# Лист — редактор резюме

Бесплатный русскоязычный редактор для соискателей России и СНГ. Первая версия работает без регистрации, серверной базы данных и платных API. Резюме редактируется и сохраняется в браузере; PDF формируется на вашем устройстве.

## Запуск

Нужны Node.js 22.12+ (проверяемая среда использует Node.js 24) и npm.

```sh
npm ci
npm run dev
```

Vite выводит адрес сервера в терминал. После повторного `npm ci` перезапустите ранее запущенный сервер разработки, чтобы сбросить кеш модулей. Для облачной среды с недоступным домашним каталогом используйте записываемый каталог кеша:

```sh
npm ci --cache /workspace/.npm
```

```sh
npm run build    # проверка TypeScript и production-сборка в dist/
npm run preview  # локальная проверка собранного приложения
npm test         # тесты модели, импорта и проверки данных
npm run test:pdf # проверка реального PDF: текст, ссылки, границы и многостраничность
npm run test:e2e # пользовательские сценарии в Chromium
```

Готовую папку `dist/` можно разместить на статическом хостинге или обслуживать локальным HTTP-сервером. Node.js нужен при разработке и сборке; серверная обработка персональных данных приложению не требуется. Доступность и стоимость стороннего публичного хостинга зависят от его условий.

Для браузерных тестов нужен Chromium. Конфигурация использует `/usr/bin/chromium`; другой путь можно передать через `CHROMIUM_PATH`. Тесты сами запускают Vite на порту 5173 либо используют уже работающий сервер. Проверяются автосохранение, импорт/экспорт JSON, скачанный PDF, записи опыта и мобильный экран. PDF-тест создаёт проверочные документы в `node_modules/.cache/workpage-pdf-check/`.

## Возможности

- Контакты, должность, город, зарплатные ожидания и формат работы.
- Описание, опыт работы и достижения, образование, навыки, языки и проекты.
- Языки выбираются из списка, расположенного ориентировочно по общему числу говорящих в мире (родной + второй язык). Это статический список, а не обновляемый демографический рейтинг. Уровни: родной, A1–C2 или без указания; для других языков доступен ручной ввод. Старые текстовые записи и произвольные уровни сохраняются.
- Добавление, удаление и изменение порядка записей; скрытие необязательных разделов.
- Необязательное фото; без даты рождения, пола и семейного положения.
- Два одноколоночных шаблона: строгий и современный; обычная и компактная плотность.
- Предпросмотр и PDF A4 с кириллицей, выделяемым текстом и ссылками.
- Разделы, помещающиеся на страницу, переносятся целиком вместе с заголовком. Разделы длиннее страницы продолжаются на следующих листах; короткие проекты внутри них также сохраняются целиком.
- Локальное автосохранение и резервные копии JSON с проверкой структуры при импорте.
- Подсказки о контактах, электронной почте, датах и длине описания.

## Данные и ограничения

Данные резюме не отправляются на сервер приложения. Шрифты включены в сборку, платные API и аналитика не подключены. Само открытие сайта всё же создаёт обычный запрос к серверу, на котором он размещён.

Автосохранение привязано к текущему браузеру, профилю и адресу сайта. Очистка данных сайта, приватный режим или смена устройства могут привести к потере локальной копии. Это не облачная синхронизация и не шифрованное хранилище. На общем компьютере удаляйте данные после работы. Регулярно экспортируйте JSON; такой файл содержит персональные данные, храните его соответственно. PDF предназначен для отправки работодателю, JSON — для продолжения редактирования.

Импорт произвольного PDF/DOCX, синхронизация, публичные ссылки, личный кабинет и ИИ не входят в первую версию. Совместимость со всеми системами автоматического отбора (ATS) не гарантируется: используется простая одноколоночная структура с текстом, но конкретную систему нужно проверять отдельно.

## Шрифты и зависимости

Noto Sans Regular и Bold находятся в `public/fonts/` и распространяются по SIL Open Font License 1.1; текст лицензии — `public/fonts/OFL.txt`. Они используются локально, без обращения к Google Fonts при редактировании и экспорте. Лицензии сторонних библиотек сохраняются в их пакетах; зависимости зафиксированы в `package-lock.json`.

Исследование, состав версии и критерии качества описаны в [docs/PRODUCT.md](docs/PRODUCT.md).
